# 小説公募プロジェクト

作成日: 2026-10-22

## 役割
- つば: 作者。本文はつばが書く。企画の最終判断もつば
- Claude: 構成作家兼編集長。企画の整理、構成（時系列・樹形図）、矛盾や穴の指摘、公募の調査
- このリポジトリは Claude の記憶置き場。時系列・人間関係・設定の矛盾を Claude が指摘するために使う（手順は CLAUDE.md）

## 目標
- 公募で受賞する。長さは短編〜中編。長編は書かない
- 狙う賞は次の2つ。二重投稿は両賞とも不可なので、別作品で2本書く

| 賞 | 締切 | 長さ | 備考 |
|---|---|---|---|
| 創元SF短編賞 第18回 | 2027-01-12 必着 | 40字×40行換算で10〜20枚（約1.6万〜3.2万字）。梗概1枚以内 | 広義のSF短編。賞金30万円。生成AIの補助利用は条件付きで可 |
| ハヤカワSFコンテスト 第15回 | 2027-03-31 必着（郵送は消印有効） | 400字詰め換算100〜800枚程度（4万字〜）。梗概5枚以内 | 広義のSF。大賞100万円。Web応募はPDFのみ、A4で40字×30行の縦書き、ノンブル必須、5MB以下 |

- 規定は2026-10-22時点の公募情報サイトの記載。応募前に必ず公式サイト（東京創元社、早川書房）で最新を確認すること
- 進め方: 創元（短編）を先に書き上げる。完了するまでハヤカワ用には着手しない

## 作風の方針（つばの好み）
- 純文学ではなく、物語の面白さで勝負する
- 説明過多は嫌い。世界のルールは地の文で解説せず、行動や会話から推測させる
- オチが読めるのも嫌い。読者に別のオチを予想させるミスリードを、伏線とセットで先に設計する
- 星新一のショートショートのミスリードが好き
- 太宰・三島のような切れ味のある文体が好き。ただし模倣はしない。今の言葉で書く
- ラブストーリーは苦手。恋愛を軸にしない
  - ただし創元用の作品（翻訳が消えた世界）では恋愛要素を扱う（つば決定 2026-10-22）
- 描きたい方向: 現代社会の風刺画（2026-10-22 つば）
- SFの発想はいくらでも出る。具体的なネタはまだ未決定
- 2026-10-22 更新: オチの仕掛けより物語の中身で勝負したい（つば）。先に決めていたミスリード重視の方針は、優先度を下げる。廃案ではない
- 2026-10-22 更新: SFにこだわらない。風刺と物語の中身が活きるジャンルを優先して公募を選び直す

## 生成AIの扱い（重要）
- 創元: 補助利用は条件付きで可。条件はつばが公式サイトで確認済み、問題なし（2026-10-22）
- ハヤカワ（第15回）: 利用した場合、梗概の末尾に具体的な使用方法を明記する。プロンプトの入出力の履歴を保存し、求められたら提示する
- 構成相談もAI利用に当たりうるため、AIとのやり取りの履歴は消さずに ai-log/ に日付ごとに保存する
- 判断に迷う点は、主催者に問い合わせる
