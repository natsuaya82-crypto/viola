# 小説公募プロジェクト

作成日: 2026-10-22

## 役割
- つば: 作者。本文はつばが書く。企画の最終判断もつば
- Claude: 構成作家兼編集長。企画の整理、構成、矛盾や穴の指摘、誤字・用語の確認、詰まったときの案出し、公募の調査。本文は書かない
- このリポジトリは Claude の記憶置き場。時系列・人間関係・設定の矛盾を Claude が指摘するために使う。運用の手順は CLAUDE.md

## 目標
- 公募で受賞する。長さは短編〜中編。長編は書かない
- 候補の賞は次の2つ。二重投稿は両賞とも不可なので、別作品で書く。応募先は未決（創元が有力）

| 賞 | 締切 | 長さ | 備考 |
|---|---|---|---|
| 創元SF短編賞 第18回 | 2027-01-12 必着 | 40字×40行換算で10〜20枚（約1.6万〜3.2万字）。梗概1枚以内 | 広義のSF短編。賞金30万円。生成AIの補助利用は条件付きで可 |
| ハヤカワSFコンテスト 第15回 | 2027-03-31 必着（郵送は消印有効） | 400字詰め換算100〜800枚程度（4万字〜）。梗概5枚以内 | 広義のSF。大賞100万円。Web応募はPDFのみ、A4で40字×30行の縦書き、ノンブル必須、5MB以下 |

- 規定は2026-10-22時点の公募情報サイトの記載。応募前に必ず公式サイト（東京創元社、早川書房）で最新を確認すること。公式の要項は、まだ確認していない
- 進め方: 創元用の作品（翻訳が消えた世界）を先に書き上げる。完了するまでハヤカワ用には着手しない

## 作風の方針（つばの好み）
- 純文学ではなく、物語の面白さで勝負する。オチの仕掛けより、物語の中身を重視する
- 説明過多は嫌い。世界のルールは地の文で解説せず、行動や会話から推測させる
- 星新一のショートショートのミスリードが好き。ミスリードは、伏線とセットで先に設計する。本作は、翻訳の設定を場面2まで隠す後出し構成で使う
- 太宰・三島のような切れ味のある文体が好き。ただし模倣はしない。今の言葉で書く
- 描きたい方向: 現代社会の風刺画
- 恋愛: ラブストーリーは苦手で、基本は軸にしない。ただし創元用の作品では、恋愛要素を扱う
- 近未来の設定は、「それにした意味は？」に答えられるものだけを採用する

## 生成AIの扱い（重要）
- 創元: 補助利用は条件付きで可。条件はつばが公式サイトで確認済み、問題なし
- ハヤカワ（第15回）: 利用した場合、梗概の末尾に具体的な使用方法を明記する。プロンプトの入出力の履歴を保存し、求められたら提示する
- 構成相談もAI利用に当たりうるため、AIとのやり取りの履歴は消さずに、ai-log/ に日付ごとに保存する。Claude が出した案で、つばが採用したものは、ai-log に一覧してある
- 判断に迷う点は、主催者に問い合わせる

## スケジュール（逆算）
- 2026年10月中: 創元用の企画と設定を固める（ほぼ完了）
- 場面ごとの初稿の目安は、plot.md の場面表を見る。初稿完了は2026年11月末
- 2026年12月: 創元用の推敲。2027年1月5日ごろまでに提出
- 2027年1月中旬〜3月: ハヤカワ用を執筆（週4,000字台が目安）
- 2027年3月20日ごろ: 推敲を終える。31日までに提出

## ファイル構成
- CLAUDE.md: Claude への運用指示（セッション開始時に自動で読まれる）
- README.md: この文書。目的、締切、方針、現在の状況
- open-items.md: 未決の一覧（現在）
- log.md: 日付ごとの決定ログ
- world.md: 世界観（裏設定）
- characters.md: 人物
- plot.md: 構成、場面表、時系列、伏線
- glossary.md: 用語集（世界特有のものの名称と機能）
- ideas.md: ネタ帳
- draft/: 本文（原稿）。parts.md がパーツ一覧
- tools/count.py: 字数を数える
- ai-log/: AIとのやり取りの記録（日付ごと）

## 運用ルール
- リポジトリは public のまま運用する（つば決定 2026-10-22）。公開されて困る情報は書かない
- 作業の最初に README.md、open-items.md、log.md を読む。区切りごとに log.md を更新して push する
